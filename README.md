
# Домашнее задание №6 — SQLAlchemy

Работа с базами данных на Python с использованием SQLAlchemy ORM.

## Описание

Программа загружает данные студентов из CSV-файла в базу данных SQLite
и позволяет выполнять запросы для анализа успеваемости.

## Реализованные возможности

- Создание модели данных Student с помощью SQLAlchemy.
- Добавление записей в базу данных (INSERT).
- Загрузка студентов из файла students.csv.
- Получение списка студентов по факультету (SELECT).
- Получение списка уникальных курсов (DISTINCT).
- Поиск студентов по выбранному курсу с оценкой ниже 30.
- Вычисление средней оценки по факультету (AVG).
- Защита от повторной загрузки данных в непустую таблицу.

## Используемые технологии

- Python
- SQLAlchemy 2.x
- SQLite
- pytest

## Структура проекта

- main.py — модель Student и методы работы с базой данных.
- students.csv — исходные данные.
- test_main.py — автоматические тесты.
- requirements.txt — зависимости проекта.

## Установка и запуск

Клонировать репозиторий или скачать проект.

Установить зависимости:

    py -m pip install -r requirements.txt

Запустить программу:

    py main.py

При запуске создаётся база данных students.db,
в которую загружаются данные из students.csv.

Программа выводит список студентов выбранного факультета,
уникальные курсы, студентов с оценками ниже 30
и средний балл по факультету.

## Тестирование

Для запуска автоматических тестов:

    py -m pytest -q

Тесты проверяют импорт CSV, добавление записей,
фильтрацию по факультету, уникальные курсы,
поиск низких оценок и вычисление среднего балла.

## Примечание

При повторном запуске данные не загружаются повторно,
если таблица уже содержит записи.

Для повторной загрузки с нуля можно удалить локальный
файл students.db и запустить программу заново.
