# Домашнее задание №9 — Сервис аутентификации

Продолжение домашних заданий №6–7: FastAPI + SQLAlchemy + SQLite.
Добавлен роутер `/auth` для регистрации, входа и выхода. Доступ к
`/students` разрешён только после входа по Bearer-токену.

## Возможности

- `POST /auth/register` — регистрация по логину и паролю.
- `POST /auth/login` — вход и выдача access-токена на 1 час.
- `GET /auth/me` — сведения о текущем пользователе.
- `POST /auth/logout` — завершение сессии и отзыв токена.
- `GET /students`, `GET /students/{id}` — чтение записей.
- `POST /students`, `PUT /students/{id}`, `DELETE /students/{id}`.
- Пользователи с флагом `is_read_only=True` могут только читать записи.

Пароли хешируются Argon2 (библиотека argon2-cffi),
индивидуальная соль генерируется автоматически.
Случайные Bearer-токены (не JWT) хранятся в SQLite только в виде
SHA-256 хешей; при выходе запись сессии удаляется.

## Запуск

Откройте папку проекта в VS Code и установите зависимости:

```powershell
py -m pip install -r requirements.txt
```

Для первоначального импорта CSV (при наличии `students.csv`):

```powershell
py main.py
```

Запустить API:

```powershell
py -m uvicorn main:app --reload
```

Swagger: http://127.0.0.1:8000/docs

1. `POST /auth/register`, например
   `{"username":"student1","password":"strongpassword123"}`.
2. `POST /auth/login` с теми же данными. Скопируйте `access_token`.
3. В Swagger нажмите **Authorize** и вставьте токен (без префикса Bearer).
4. Теперь можно работать с `/students`.
5. Для завершения сессии вызовите `POST /auth/logout`.
   Старый токен перестанет работать.

## Доступ только на чтение

Зарегистрируйте пользователя, затем локально в терминале выполните:

```powershell
py set_read_only.py student1
```

После этого пользователь может выполнять только `GET /students` и
`GET /students/{id}`. Для POST, PUT и DELETE сервер возвращает `403`.
Администрирование роли выполняется локально, а не через открытый API.

## Тесты

```powershell
py -m pytest -q
```

`test_main.py` проверяет функции ДЗ №6. `test_api.py` проверяет
регистрацию, вход, выход, защиту CRUD, 401/403/404 и срок действия токена.

## На основе материалов курса

- `argon2_salt.py`: хеширование и проверка паролей через Argon2.
- `authn_id.py` и схемы вебинара: проверка пользователя и отзыв сессии.
- `authn_jwt.py`: альтернативный подход с JWT.
  В данной работе используются случайные токены с серверными сессиями,
  чтобы выход сразу делал токен недействительным.
- `hashlib_wo_salt.py` показывает пример простого хеширования,
  **не подходящего для хранения паролей**.
