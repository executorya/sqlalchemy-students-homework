# Домашнее задание №6-7 — REST API. Реализация CRUD

Доработка проекта по SQLAlchemy из домашнего задания №6.

## Описание

REST API для работы с данными студентов.
Приложение использует FastAPI, Pydantic, SQLAlchemy и SQLite.

## Возможности

- Создание студента — POST /students
- Получение студентов — GET /students
- Получение студента по ID — GET /students/{id}
- Фильтрация по факультету — GET /students?faculty=ФПМИ
- Обновление студента — PUT /students/{id}
- Удаление студента — DELETE /students/{id}

Сохранены функции из предыдущего задания:
импорт CSV, поиск по факультету, уникальные дисциплины,
поиск оценок ниже 30 и вычисление средней оценки.

## Установка

Установить зависимости:

    py -m pip install -r requirements.txt

## Запуск

Перед первым запуском API загрузить данные CSV:

    py main.py

Запустить FastAPI:

    py -m uvicorn main:app --reload

Документация Swagger:

http://127.0.0.1:8000/docs

## Пример создания студента

POST /students

    {
        "last_name": "Иванов",
        "first_name": "Петр",
        "faculty": "ФПМИ",
        "course": "Физика",
        "grade": 85
    }

При успешном создании сервер возвращает код 201.

Если студент не найден, возвращается 404.
При ошибке валидации входных данных — 422.

## Тестирование

Запуск тестов:

    py -m pytest -q

Тесты проверяют операции CRUD, фильтрацию и ошибки API.

## Структура проекта

- main.py — модели, класс работы с БД и FastAPI.
- test_main.py — тесты предыдущего задания.
- test_api.py — тесты CRUD.
- students.csv — исходные данные.
- requirements.txt — зависимости проекта.
